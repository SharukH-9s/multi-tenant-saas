# Information security basics

## Accounts and passwords

Passwords must be at least fourteen characters long. Use the company password manager and never reuse a password from another service.

## Multi-factor authentication

Multi-factor authentication (MFA) is mandatory for email, the code repository and the admin console. Hardware security keys are preferred over SMS codes, and SMS codes are accepted only as a fallback.

## Devices

All laptops use full-disk encryption and lock automatically after five minutes of inactivity. A lost or stolen device must be reported to the security desk within one hour.

## Reporting incidents

Report a suspected phishing email by forwarding it to the security mailbox. Do not click links or open attachments first.
